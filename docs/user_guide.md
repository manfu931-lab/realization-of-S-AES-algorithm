# 用户指南

## 环境与启动

Python 3.10+，无需第三方包。Windows 双击 `run.bat`；其他系统在项目目录运行 `python main.py`。若 GUI 无法启动，先运行 `python -m unittest discover -s tests -v` 检查算法。

## 单块 / 多重

输入 4 位十六进制分组。模式 `S-AES` 使用 4 位密钥；`Double` 使用 8 位密钥，按左 4 位 K1、右 4 位 K2 依次加密；`Triple` 使用 12 位密钥，按 K1、K2、K3 做 EEE。解密使用逆序密钥。选择“加密”或“解密”后输出 4 位 Hex。

例如 `S-AES`，分组 `D728`，密钥 `4AF5`，加密结果 `24EC`。

## ASCII 文本

输入 ASCII 文本和 4 位密钥。程序按两个字节分组，以 PKCS#7 补齐，再对每组执行 S-AES，输出 Hex。解密时将 Hex 密文粘贴到对应输入框。中文不属于 ASCII；中文文本请用 CBC 页的 UTF-8 输入。

## 中间相遇

每行输入一组 `明文Hex 密文Hex`，如 `D728 A656`。点击搜索后程序在后台枚举全部 65536 个 K1 与 K2，按第一组中间值匹配，再用余下明密文对筛选。单对通常仍有大量候选；建议输入至少三组。结果列出全部候选数，最多显示前 100 个密钥。

## CBC

输入 UTF-8 文本和 4 位密钥。加密时 IV 留空会随机生成 16 位 IV，并回填在界面；也可指定 4 位 Hex IV 复现实验。将 **IV、密文 Hex、密钥** 提供给解密方。密文仅是 Hex 编码，不含 IV。测试篡改时可修改密文前部的一位，再用原 IV 解密；输出可能改变，若改动碰到填充，还可能报填充错误。
