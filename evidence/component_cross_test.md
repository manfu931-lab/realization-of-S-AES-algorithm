# 附录 D 组件交叉测试

本组用下列数据检查 S-AES 组件，也将其作为与外组独立实现逐项对照的参考。表格由本组程序生成，并已核对附录 D 的 S 盒、列混淆矩阵、有限域与密钥扩展示例。现有外组截图只展示整块加解密结果，未展示逐组件状态。

本组采用的状态顺序为：四位 Hex `n0n1n2n3` 对应矩阵 `[[n0,n2],[n1,n3]]`，每一步的输出均写回 `n0n1n2n3`。密钥和明密文采用相同的四位 Hex 表示。

| 组件 | 输入 | 预期输出 | 附录 D 对应规则 |
| --- | --- | --- | --- |
| S 盒 | `A` | `0` | 表 D.1 |
| 逆 S 盒 | `0` | `A` | 表 D.1 |
| GF(2⁴) 乘法 | `4 × C` | `5` | 附录 D.1，模 `x⁴+x+1` |
| 行移位 | `B784` | `B487` | 第二行两个半字节交换 |
| 列混淆 | `6C40` | `3743` | 矩阵 `[[1,4],[4,1]]` |
| 逆列混淆 | `3743` | `6C40` | 矩阵 `[[9,2],[2,9]]` |
| 密钥扩展 | `2D55` | `K0=2D55,K1=BCE9,K2=A34A` | 轮常数 `80,30` |

本组在项目根目录执行 `python tools/component_trace.py 1234 2D55`，得到覆盖所有步骤的完整向量：

| 步骤 | 预期状态 |
| --- | --- |
| K0 | `2D55` |
| K1 | `BCE9` |
| K2 | `A34A` |
| AddKey0 | `3F61` |
| SubNib1 | `B784` |
| ShiftRow1 | `B487` |
| MixColumn1 | `8E71` |
| AddKey1 | `3298` |
| SubNib2 | `BA26` |
| ShiftRow2 | `B62A` |
| Ciphertext | `1560` |

逐组件对照采用 `P=1234`、`K=2D55`。若另一实现输出每步状态，两份结果的第一处差异可以定位到相应组件。本组对这一输入计算得到密文 `1560`，解密恢复 `1234`。这组逐组件向量是本组的参考数据，不属于现有外组截图的测试内容。

仅比较最终密文，可能无法定位出错的组件；本程序内部加解密往返也不足以单独证明符合附录 D。因此本组保留了上述组件参考值，供独立实现对照。
