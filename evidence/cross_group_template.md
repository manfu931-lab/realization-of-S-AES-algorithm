# 第 2 关：组间交叉测试记录

本地算法向量已列于 `cross_vectors.csv`。这里的“相同算法”指双方独立程序都使用教材附录 D 的同一套 16 位 S-AES 参数；不要求编程语言或界面相同。2026-10-26 收到用户提供的三张截图：第一张为对方程序，第二、三张为本项目程序。截图显示同一组数据的双方加密与解密一致；对方组名、程序版本和另一组非默认向量尚未提供。

## 第一步：你们先确认规则一致

| 待核对项目 | 双方应采用的规则 | 对方确认 |
| --- | --- | --- |
| 分组与密钥 | 原始 S-AES 均为 16 位；本关先测单块，不用 CBC、填充或双重加密 | 待填写 |
| 状态排布 | `n0n1n2n3` → `[[n0,n2],[n1,n3]]`，先填第一列 | 待填写 |
| S 盒 | `9 4 A B / D 1 8 5 / 6 2 0 3 / C E F 7` | 待填写 |
| 有限域 | GF(2⁴)，模多项式 `x⁴+x+1` | 待填写 |
| 列混淆 | 正向 `[[1,4],[4,1]]`，逆向 `[[9,2],[2,9]]` | 待填写 |
| 密钥扩展 | 轮常数 `80`、`30`；`2D55` → `K0=2D55,K1=BCE9,K2=A34A` | 待填写 |
| 加密顺序 | `AddKey0→SubNib→ShiftRow→MixColumn→AddKey1→SubNib→ShiftRow→AddKey2` | 待填写 |

如果某项不一致，先按附录 D 核对并修正程序，再进行交叉测试。不同语言可使用 Hex 或二进制输入，但双方需要确认数值完全相同。

## 第二步：你和对方分别执行

1. 你打开本项目 GUI 的“单块 / 多重”页，模式 `S-AES`，输入明文 `1234`、密钥 `2D55`，点击“加密”，记录密文；预期为 `1560`。对方在自己的程序输入完全相同的数值并记录密文。
2. 对方用其程序解密你生成的密文 `1560`、密钥 `2D55`，应得到 `1234`。你再用本项目解密对方生成的密文，亦应得到 `1234`。
3. 再测一组：明文 `D728`、密钥 `4AF5`，本项目加密结果为 `24EC`。双方重复加密与互相解密。
4. 若结果不同，双方运行逐组件测试并比较第一处差异。本项目命令：`python tools/component_trace.py 1234 2D55`；详细参考值见 `component_cross_test.md`。

二进制输入可用：`1234 = 0001001000110100`，`2D55 = 0010110101010101`，`1560 = 0001010101100000`。每组截图应显示程序、输入、输出；记录对方程序的语言、版本、日期和参与者。
